AI Quiz — Landing design concepts

Five self-contained design directions for the quiz website homepage. Each file is a single, dependency-free HTML page with inline CSS — open any of them directly in the IDE preview or a browser.

🌌
Design 01

Aurora Glass

Dark glassmorphism with animated aurora blobs, gradient headline, glass game cards and neon stats. Premium night-mode feel.
🟥
Design 02

Neo Brutalist

Chunky black borders, hard shadows, sticker emojis, scrolling marquee. Loud, playful and impossible to ignore.
🌸
Design 03

Pastel Playful

Soft pastel blobs, rounded cards, gentle shadows and a friendly wave. Approachable and kid-safe feeling.
🕹️
Design 04

Retro Arcade

CRT scanlines, starfield, neon glow text, INSERT COIN energy and per-game high scores. Full 80s cabinet vibe.
📰
Design 05

Editorial Minimal

Serif italic headlines, numbered sections, hairline rules, generous whitespace. Quiet, confident, premium.
How to use these: every file is standalone HTML + CSS (no build step). Open any file in the IDE and hit Alt+D / right-click → Open in browser, or just double-click it. All five share the same real site content (Quiz MCQ · Riddle MCQ · Image Riddles · Dad Jokes · live stats · Joke of the Day), so they're drop-in comparisons for redesigning app/page.tsx.

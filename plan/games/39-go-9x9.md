# 39 — Go 9×9 (empty-board family)

> **Status:** PLANNED — batch L. Template: [README.md](README.md) §1.
> The deepest game ever played, on the duel-sized board. Completely empty board — the
> first stone is the first player's decision. The hard tier is honest search + heavy
> heuristics, NOT a world-class engine: stated openly so expectations stay sane.

## 1. Nine-line spec

1. **Name:** Go 9×9
2. **One-liner:** surround territory with stones — capture by removing liberties, win by the bigger wall count
3. **How to win:** more territory + captures when both players pass
4. **The board:** 9×9 intersections, no stones at start; a move = place one stone on any
   empty intersection (or pass when legal)
5. **Turns:** alternation; stones with no liberties are captured immediately; suicide is
   illegal unless it captures; two consecutive passes end the game
6. **Solo AI:** easy = random-ish legal points, avoids self-atari · medium = captures,
   saves groups in atari, basic territory instinct · hard = alpha-beta/MCTS with
   liberty-group heuristics — **strong amateur, explicitly not perfect**
7. **Duel:** turn-based live, invite code; server validates legality, applies captures, resolves the score
8. **Toggles:** komi 5.5 (default) / 0 · board 9×9 fixed in v1 (13×13/19×19 never — duel length)
9. **Never:** no levels, no pre-filled anything

## 2. Rules

- A stone/group's liberties = adjacent empty intersections; zero liberties = capture.
- No board repetition (simple ko rule: recreating the immediately previous position is
  illegal).
- Two passes → scoring: area scoring (stones + territory + captures), komi to white.

## 3. Board model (`core.js`, pure)

- State: `points: (0|1|2|null)[81]`, `turn`, `passes`, `koPoint`.
- `groupAt(state, idx)` (chain + liberties) · `applyPlace(state, idx)` with capture
  resolution + suicide/ko checks · `scoreArea(state, komi)`. Capture math is the deep
  pure part — jest-tested on classic capture/ko/eye shapes.

## 4. Solo AI

| Tier   | Behaviour                                                                           |
| ------ | ----------------------------------------------------------------------------------- |
| Easy   | Random legal point, filtered to avoid instant self-atari                            |
| Medium | Takes captures, extends atari groups, prefers 3rd/4th-line early moves              |
| Hard   | MCTS (few-hundred-rollout budget on phone) with group-liberty + territory features; |
|        | strong club amateur. Explicitly strong-not-perfect.                                 |

## 5. Online duel (backend)

- ttt-pattern clone (`/go9`): match row holds `points`, `turn`, `passes`, `koPoint`,
  `status`, guest ids, `expiresAt` (extended TTL — long games; abandoned-on-silence as
  duels do). Server re-validates ko/suicide, applies captures, resolves the score on
  two passes. 3-second poll sync.

## 6. UI / rounds

Goban with wood texture, stone shadows, last-move marker, capture counter, pass button
with confirm, territory tint preview at end. Rematch = colour swap. Rounds run 8–20 min
on 9×9.

# Four-Player 50 — the full 4P expansion list (empty-board family)

> **Owner decision 2026-09-28:** the base party roster (F1–F10 = P1–P10 in
> [multiplayer-party.md](multiplayer-party.md)) is the build-now scope. This file plans
> the expansion to **50 four-player games**. Seat rule, bot-fill, placement and the
> engine are unchanged (MP1: [multiplayer-party-plan.md](multiplayer-party-plan.md)) —
> every row is another adapter on the same 4-seat engine.
>
> **Tags:** [native] = traditionally/officially supports 4P · [variant] = our adaptation of a
> confirmed family game · [original] = new design · [RNG] = dice/cards, activates only
> after the owner's luck-tier decision. **No word lists, no served content anywhere.**

## Composition + gating

- **No RNG needed:** F1–F4, F11–F32, F43–F50 = **34 games** buildable today on the family rules.
- **RNG-gated:** F5–F10 (the base dice/card roster) + F33–F42 = 16 rows that activate with
  the luck-tier decision (Pig Dice's server-roll is the precedent).
- **Waves:** base F1–F10 (now) · Wave A F11–F26 · Wave B F27–F32 · Wave C F33–F42 (gated) ·
  Wave D F43–F50 (the L-bosses land with the Go/Chess cores).
- Every row rides the same MP1 engine — a new game is an adapter + UI, not new plumbing.
- Team rows (F40, F41) need a 2v2 seat layer in MP1 (partners share a placement) — flagged
  before anyone builds them.

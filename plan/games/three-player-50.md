# Three-Player 50 — the full 3P expansion list (empty-board family)

> **Owner decision 2026-09-28:** the base 3P set (T1–T10, [three-player-games.md](three-player-games.md))
> is the build-now scope. This file plans the expansion to **50 three-player games**.
> Seat rule, bot-fill, placement and the engine are unchanged (TP1:
> [three-player-plan.md](three-player-plan.md)) — every row below is just another adapter
> on the same 3-seat engine.
>
> **Tags:** [native] = traditionally/officially supports 3P · [variant] = our adaptation of a
> confirmed family game · [original] = new design · [RNG] = dice/cards, activates only
> after the owner's luck-tier decision. **No word lists, no served content anywhere.**

## Composition + gating

- **No RNG needed:** T1–T32 and T43–T50 = **40 games** buildable today on the family rules.
- **RNG-gated:** T33–T42 = 10 rows that activate with the luck-tier decision (Pig Dice's
  server-roll is the precedent).
- **Waves:** base T1–T10 (now) · Wave A T11–T26 · Wave B T27–T32 · Wave C T33–T42 (gated) ·
  Wave D T43–T50 (the L-bosses land with the Go/Chess cores).
- Every row rides the same TP1 engine — a new game is an adapter + UI, not new plumbing.

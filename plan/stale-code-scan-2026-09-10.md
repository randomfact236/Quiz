**Three significant bugs fell out of the scan (all in uncommitted or lightly-traveled code):**

1. **Guest `publicId` is write-broken in production** — the new migration adds the column with no `DEFAULT gen_random_uuid()` while the entity promises one; with `synchronize:false`, any insert that omits `publicId` (the raw-SQL `recordSessionCompletion` is guaranteed) hits a NOT NULL violation on a migrations-only deploy. (F01)
2. **Bulk riddle import rejects every CSV containing an expert row** — `BulkCreateRiddleDto.correctLetter` is `@IsNotEmpty`-required, but the import modal legitimately omits it for expert rows (text `answer` instead); the global `forbidNonWhitelisted` pipe 400s the whole chunk. (F03)
3. **Password-reset/verification emails are broken behind a comma-separated `CORS_ORIGIN`** — the email link base reads `CORS_ORIGIN`, which `.env.example` documents as a comma-separated list; with >1 origin the emailed URL is garbage. `FRONTEND_URL` (which OAuth actually uses) is missing from both env examples entirely. (F01)

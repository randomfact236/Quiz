3 · Consistency rules (final)

One master image per item — 1200×630, family gradient (quiz = brand purple · riddle = teal · joke = amber · game = per-game accent), item emoji/text inside the central square SAFE ZONE.
Answer visibility: tease what requires participation — quiz questions and riddles share without answers; deliver what is consumption — dad jokes share with the punchline; image riddles share the photo only.
Options in the image render per question type (yes/no → 2 pills · 2/3/4 → grid matching the site's AnswerOptions layout · open-ended → none) and the correct option is never marked.
Text: title ≤ 60 · description ≤ 110 · WhatsApp message carries the personal line + link. Less or more is fine — platforms truncate gracefully.
URLs: always the durable surface (subject / category / game), never a rotting session link. Games stay dependency-free; bump ?v=N when editing their files.
